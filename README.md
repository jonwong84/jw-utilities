# utilities

A collection of utilities for my projects.

## Utilities.Configuration

A utility for managing configuration settings in .NET applications. It provides a simple interface for loading, saving, and accessing configuration data, making it easier to manage application settings across different environments.

This Configuration utility allows you to retrieve config values from AppSettings, ConnectionString, and EnvironmentalVariables. Also has fields in place for future implementation of the ability to retrieve values from external configuration stores.
